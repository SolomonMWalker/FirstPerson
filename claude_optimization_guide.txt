  1. CombatAgent._PhysicsProcess — overlap query every frame                                                                                                                        
  src/agents/enemies/baseClasses/CombatAgent.cs (line 173)                                                                                                                          
  if (!inCombat && CombatTriggerArea.HasOverlappingAreas())
  {
      var overlapArea = CombatTriggerArea.GetOverlappingAreas().First(); // allocates + LINQ
  Every non-combat enemy does two overlap queries and a LINQ allocation per physics frame. With 20 enemies this is 40 physics queries/frame. Replace with body_entered/area_entered
  signals so it only fires when something actually enters.

  2. MovingAgent.MoveToPoint — MapGetClosestPoint every frame
  src/agents/enemies/baseClasses/MovingAgent.cs (line 54)
  NavigationAgent3D.TargetPosition = NavigationServer3D
      .MapGetClosestPoint(_navMapId.Value, NavigationAgent3D.TargetPosition);
  A nav server RPC call every physics frame per moving enemy. Only recalculate when the target actually moves (cache the last snapped position and skip if target hasn't changed).

  3. StateMachine.HandleChangeStateEvent — linear search per transition
  src/CustomTypes/StateMachine/StateMachine.cs (line 62)
  var path = PathsToAtomicStates.FirstOrDefault(p => p.AtomicState.Name == args.StateName);
  PathsToAtomicStates is a List<>, so every state change does an O(N) scan. Swap it for a Dictionary<string, PathToAtomicState> built in _Ready — this hits every enemy every time
  they transition states in combat.

  High

  4. CombatAgent._Ready — double signal subscription
  src/agents/enemies/baseClasses/CombatAgent.cs (lines 38–44 and 119–127)
  The OnCombatStart handler is connected once in the EncounterZone property setter and again in _Ready, so it fires twice every combat start. Remove the one in the property setter
  (keep _Ready authoritative).

  5. CombatAgent._Ready — hitbox signal handlers never disconnect
  src/agents/enemies/baseClasses/CombatAgent.cs (lines 129–141)
  ~4 hitboxes × 20 enemies = 80 signal handlers that are never disconnected in _ExitTree. Add _ExitTree cleanup or use Callable.Bind with weak references.

  6. Dog shape casts every frame
  src/agents/enemies/testDog/Dog.cs (line 86)
  Three ShapeCast3D.IsColliding() queries run every physics frame regardless of whether the dog is attacking. Gate them behind an "is in attack window" bool so they only run when
  relevant.

  7. All AI nav components — GetNavigationMap() every frame
  AgentFollowComponent, AgentPatrolComponent, AgentZigzagComponent, AgentStopComponent
  if (NavigationServer3D.MapGetIterationId(NavigationAgent3D.GetNavigationMap()) == 0)
  _navMapId is already cached in MovingAgent but isn't being passed through. Cache the map Rid in each component's _Ready instead of re-fetching it.

  Medium

  8. StaggerComponent and ShieldComponent — polling in _Process
  Both poll RechargeTimer.IsStopped() every frame. Replace with a Timer.Timeout signal that sets a bool to start recharging, then SetProcess(false) until it fires — 1,200
  unnecessary checks/sec across 20 enemies.

  9. Dog.HandleMeleeAttackCollision — list reallocation + O(N) Contains
  src/agents/enemies/testDog/Dog.cs (line 112)
  meleeAttackObjectsHit = []; // new allocation every attack
  Reuse the list with .Clear(). Also change meleeAttackObjectsHit from List<> to HashSet<> so Contains() is O(1).

  10. PlayerController._Process — string allocations every frame
  HealthLabel.Text = $"Health: {(int)HealthComponent.CurrentHealth}/...";
  Allocates two strings per frame (~120/sec). Cache the previous values and only update the label text when they change.

  11. CompoundState.TryGetStateByName — Name.ToString() in predicate
  src/CustomTypes/StateMachine/CompoundState.cs (line 65)
  state = ChildrenStates.FirstOrDefault(s => s.Name.ToString().Equals(stateName));
  Called on every state transition. Cache the string representation of Name in each state's _Ready instead of calling ToString() on every comparison.

  12. Hitbox.Hit — repeated weakspot check
  The HitboxType == Type.Weakspot enum check runs separately for both health and stagger damage. Compute the multipliers once at the top and reuse.
